# Yandex Disk Commander — порт для Windows

[![Лицензия: LGPL v2.1+](https://img.shields.io/badge/License-LGPL%20v2.1%2B-blue.svg)](LICENSE)

> [English](README.md) | **Русский**

Плагин файловой системы (WFX) для **Total Commander** и **Double Commander**, который
позволяет работать с **Яндекс Диском** прямо из файлового менеджера в Windows 10/11 x64.

Проект вдохновлён [ivanenko/ydisk_commander](https://github.com/ivanenko/ydisk_commander)
(оригинальный плагин для Linux от Danil Ivanenko), но код **почти полностью переписан
с нуля под Windows 10 x64**: WinHTTP вместо cpp-httplib + OpenSSL, защита токена через
DPAPI, нативные Win32-диалоги, создаваемые во время выполнения, вместо GTK/LCL, и простой
Winsock-сервер для OAuth callback. С оригинальным проектом общие только встроенная
библиотека [json11](https://github.com/dropbox/json11), заголовок WFX SDK и общий набор
возможностей.

## Возможности

- Просмотр, скачивание, закачка, создание папок (F7), переименование/перемещение (F6),
  копирование (F5) и удаление (F8) файлов и папок на Яндекс Диске
- Корзина: папка `/.Trash`, удаление отдельных файлов, команда очистки корзины
- Серверное скачивание файлов из интернета напрямую на диск
  (`quote download <url>`) — трафик не проходит через ваш ПК
- Подсчёт размера папок (Alt+Shift+Enter)
- OAuth 2.0 авторизация через Яндекс ID — три способа (см. ниже)
- Гибкое хранение токена: не хранить / ini-файл с шифрованием DPAPI / менеджер паролей
  Total Commander
- Юникодные имена файлов, файлы больше 4 ГБ, прогресс передачи с отменой
- Никаких внешних зависимостей — только системные DLL (WinHTTP, DPAPI, Winsock)
- Собственные диалоги плагина отображаются на языке интерфейса Total Commander
  (русский/английский)

## Установка

1. Скачайте `ydisk_commander.wfx64` со страницы
   [Releases](../../releases) (или соберите сами — см. ниже).
2. В Total Commander: **Конфигурация → Настройка → Плагины → Плагины файловых систем
   (.WFX) → Настроить → Добавить** и выберите скачанный файл.
3. Откройте **Сетевое окружение** в Total Commander — появится пункт **Yandex Disk**.

> **Примечание:** Total Commander блокирует файл плагина во время работы. Закройте
> Total Commander перед заменой плагина на новую сборку.

## Настройка

В Сетевом окружении нажмите правой кнопкой на **Yandex Disk → Свойства** (или Alt+Enter),
чтобы открыть диалог настроек.

### Получение OAuth-токена

Доступны три способа:

- **Код подтверждения (device flow, по умолчанию)** — плагин показывает короткий код и
  ссылку. Откройте ссылку в любом браузере, войдите в Яндекс и введите код. Локальный
  слушатель не требуется, работает за строгими файрволами.
- **Браузер + локальный callback** — плагин поднимает временный веб-сервер на
  `127.0.0.1:3359`, открывает страницу авторизации Яндекса и автоматически перехватывает
  токен из редиректа.
- **Ввести токен вручную** — вставьте уже имеющийся токен.

Кнопка **Test connection** проверяет токен и показывает квоту диска
(всего / занято / свободно).

### Хранение токена

- **Не сохранять** — токен живёт только в памяти и запрашивается заново при следующем
  запуске Total Commander.
- **Файл конфигурации** — токен хранится в ini-файле плагина, зашифрованный Windows DPAPI
  (расшифровать его может только ваша учётная запись Windows).
- **Менеджер паролей Total Commander** — токен хранится самим Total Commander
  (защищён мастер-паролем, если он включён в TC).

Отозвать токен позже можно в **Яндекс ID → Доступы к данным** (или «Выйти везде»).

## Команды

Вводите в командную строку Total Commander, когда активна панель с Яндекс Диском:

- `quote trash` — перейти в корзину (`/.Trash`)
- `quote trash clean` — навсегда удалить всё содержимое корзины (запрашивает
  подтверждение)
- `quote download <URL> [новое_имя]` — приказать Яндекс Диску скачать файл из интернета
  **на стороне сервера** в текущую папку; `новое_имя` — необязательный параметр

Файлы в корзине также можно удалять по одному клавишей F8 из папки `/.Trash`.

## Сборка из исходников

Требования:

- **MinGW-w64 g++** (достаточно C++11), например с [winlibs.com](https://winlibs.com)
  или из MSYS2, с `g++.exe` в `PATH`
- **PowerShell** 5+

Сборка:

```powershell
scripts\build.ps1          # build\ydisk_commander.wfx64 (64 бита, для 64-битного TC)
scripts\build.ps1 -Test    # то же + сборка и запуск тестов build\smoke.exe
scripts\build.ps1 -X86     # build\ydisk_commander.wfx (32 бита, для 32-битного TC)
```

Режим `-X86` требует 32-битный тулчейн MinGW; без него он всё равно компилирует
исходники и проверяет, что определения экспорта совпадают с полученными символами.

Плагин линкуется только с системными библиотеками (`winhttp`, `crypt32`, `ws2_32`,
`shell32`, `user32`, `gdi32`) — сторонних зависимостей устанавливать не нужно.

## Структура проекта

| Путь | Описание |
| --- | --- |
| `src/plugin.cpp` | Точки входа WFX (Unicode API + тонкие ANSI-обёртки) |
| `src/restclient.*` | Клиент Web API Яндекс Диска |
| `src/http_client.*` | Транспорт WinHTTP с прогрессом и отменой |
| `src/http_server.*` | крошечный локальный HTTP-сервер для OAuth callback в браузере |
| `src/auth.*` | OAuth 2.0 потоки (device code, browser callback, вручную) |
| `src/dialogs.*` | нативный Win32-диалог настроек, создаваемый во время выполнения |
| `src/plugin_utils.*` | преобразование UTF-8/UTF-16, пути, ini-файл, DPAPI, язык интерфейса |
| `src/json11.*` | встроенная JSON-библиотека |
| `src/wfxplugin.h` | объявление интерфейса WFX Total Commander |
| `tests/smoke.cpp` | смоук-тесты (конфиг, DPAPI, HTTP, JSON) |
| `scripts/build.ps1` | скрипт сборки |
